CHAPTER 3
AI Agents Explained
Chatbot vs Agent: A chatbot responds to questions. An agent takes actions — it plans a sequence of steps, uses tools (APIs, databases, apps), and completes work independently.
Multi-step work: An agent can receive a task ("prepare the quarterly report"), break it into steps, gather data from multiple sources, analyse it, write the report, and send it — without human intervention at each step.
Agentic era: Google's Gemini Enterprise is built specifically for this — agents that interact across multiple enterprise systems with the same reliability as a human team member.
Key capability: Agents in Gemini Enterprise can use Google Workspace, external APIs, corporate databases, and cloud services as tools — connecting your entire business ecosystem.

Security & Governance
Agent Registry: A centralised directory of all agents in your organisation — who built them, what they do, what permissions they have. No shadow AI.
Semantic Policies: Write governance rules in plain language — "never share customer PII outside the EU" — and the platform enforces them automatically across all agents.
Data Residency: Gemini Enterprise supports standard Data Location (DRZ) commitments in US, EU, and global multi-regions — critical for GDPR and Nigerian NDPA compliance.
CVE patching: Security vulnerabilities (like CVE-2026-1727, the bucket squatting issue) are patched automatically — no action required from customers.
